## ✨ Sobre o projeto

O **Pointer** é uma aplicação SaaS front-end para gerenciamento de jornada de trabalho, permitindo:

- registro de entrada e saída
- controle de pausas
- histórico de registros
- dashboard com métricas
- relatórios
- gerenciamento de funcionários
- modo escuro
- responsividade mobile

O sistema foi desenvolvido utilizando apenas tecnologias web puras, sem frameworks, visando aprendizado, performance e domínio completo da estrutura do projeto.
